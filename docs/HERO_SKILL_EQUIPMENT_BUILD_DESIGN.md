### 1.3 当前主要问题

1. 现有 AI 先按复活、治疗、群攻/单攻、其他分类，再在同类技能中随机选择，无法稳定表达玩家策略。
2. 治疗候选目前没有严格要求友军已损血，存在无效治疗优先释放问题。
3. 神将推荐装备主要依据原始职业，无法区分同职业内部的护盾、反击、追击、持续伤害等流派。
4. 低稀有度角色中有 8 名仍使用“垃圾小怪兽”占位特征，缺少产品定位。
5. 神将技能有大量重复名称；`清心`重复 8 次，多个技能共享效果引用，角色辨识度不足。
6. 24 个神将被动技能没有技能图标。
7. 技能文案存在 `%%`、错误参数引用、重复文字等数据问题，不能直接作为新策略系统的解释文本。
8. 当前 10 套装备已经有流派雏形，但部分套装的 2/4 件效果主题不统一，例如“反震伤害+开场护盾”。

## 三、技能流派系统设计

### 3.1 四技能的新职责

不能机械地规定“第二主动技能一定是战法”。现有技能中，哪吒的第二主动为 CD0 常规攻击，而女娲的第二主动为 CD6 复活。应通过配置逐技能指定：

| 职责 | 数量 | 行为 |
|---|---:|---|
| 常规技 | 1 | 自动释放，受 CD 和策略规则控制 |
| 战法 | 1 | 消耗全队战意，可手动插入或按规则自动释放 |
| 核心被动 | 1 | 定义主要流派，可由天赋分支改变 |
| 联动被动 | 1 | 生存或队伍联动，可由装备强化 |

新增 `cast_mode` 明确职责，不根据技能槽顺序推断。

### 3.2 策略规则

每个阵容保存一个策略预设，每名神将最多 5 条优先规则：

`优先级 → 条件组 → 目标规则 → 技能/普攻 → 战意保留 → 失败回退`

首版必须支持：

- 友方阵亡数量。
- 最低生命值和低血人数。
- 敌方是否有护盾、增益、禁疗、中毒、灼烧或控制免疫。
- 敌人数量、首领标签和蓄力阶段。
- 自身生命、负面状态、护盾状态和技能 CD。
- 当前战意与最低保留战意。

技能候选必须确定性评分，不允许同条件下随机选择。

### 3.4 天赋分支

每名首批神将设计 4 层二选一，不增加新的主动技能按钮：

1. 资源层：战意获取 / 战意消耗。
2. 常规技层：目标、次数、持续时间或 CD。
3. 核心被动层：改变触发方式或联动对象。
4. 战法层：强化救场、爆发或控制方向。

每名神将最终形成两套完整预设，天赋节点必须改变行为，禁止全部做成纯属性百分比。

## 四、装备流派系统设计

### 4.1 保留并重整现有10套装备

### 4.2 装备组成

每件当前可穿戴的神将装备建议由以下部分组成：

`部位固定主属性 + 品质词条数 + 随机副词条 + 可选流派特效 + 套装ID + 强化/精炼值`

首版不增加新装备部位和新货币，继续使用当前4装备位、2法宝位以及已有强化、精炼、洗炼和套装入口；法宝词条单独设计。

### 4.3 词条分组

| 词条组 | 示例 | 适用流派 |
|---|---|---|
| 生存 | 最大生命、双防、免伤、护盾效率、被治疗 | 肉盾、护盾、复活 |
| 速度 | 速度、开场行动条、受治疗加速 | 控制、先手、辅助 |
| 精准 | 命中、负面强化、忽视防御 | 控制、破甲、持续伤害 |
| 爆发 | 暴击、暴伤、对低血增伤、对首领增伤 | 斩杀、暴击 |
| 频率 | 连击、反击、追击伤害、额外行动限制 | 连击、追击、反击 |
| 持续 | 中毒/灼烧/流血增伤、持续回合、异常目标增伤 | 灵系、异常联动 |
| 治疗 | 治疗效果、溢出转盾、复活后保护 | 治疗、复活、护盾 |
| 战意 | 开场战意、每回合产出、战法消耗、溢出转化 | 所有战法流派 |

### 4.4 首批流派特效

首版只制作 16 条特效，每个流派 1–2 条，不直接制作数百条：

- 援护触发反击；单回合最多2次。
- 反震伤害的一部分转为护盾；单回合有总量上限。
- 击杀后常规技 CD-1；单回合一次。
- 连击最后一段对低血目标增伤。
- 暴击未发生时累积暴击补偿，暴击后清除。
- 对护盾目标无视部分防御，破盾后获得战意。
- 成功施加控制后为全队增加战意；每回合一次。
- 有效治疗后使目标行动提前，但同目标两回合内只触发一次。
- 溢出治疗转化为护盾。
- 复活目标获得一回合保护，禁止连续复活循环。
- 中毒达到指定层数后扩散一层。
- 灼烧结束或被驱散时造成一次结算伤害。
- 禁疗目标受到治疗时降低其行动条。
- 护盾消失时按实际吸收量造成伤害。
- 战法释放后强化下一次常规技。
- 每保留一定战意提高防御，释放战法后清除。

### 4.5 推荐装备逻辑

废止“职业类型直接推荐固定两套”的单层规则，改为：

`神将主定位 + 已选天赋分支 + 策略预设 + 当前装备词条 → 推荐套装、主词条、副词条和法宝`

推荐界面至少给出：

- 推荐原因。
- 当前流派匹配度。
- 更换后关键机制变化。
- 是否破坏 2/4 件套。
- 通用战力与流派收益两个独立评分。
