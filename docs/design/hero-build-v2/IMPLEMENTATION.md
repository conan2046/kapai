## 协议枚举

- branch：0基础、1=A、2=B。
- strategy：0旧策略、1救场、2守护、3控制、4爆发、5持续。
- 保存格式：`branch | (strategy << 2)`。读取时校验两个字段，非法值不进入战斗策略。
- 不同角色对应独立扩展键，不按阵位存档。共享技能（例如准提/武吉的122）后续必须按神将ID及分支判断，禁止全局改共享效果表。
