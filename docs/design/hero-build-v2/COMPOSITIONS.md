## 2. 配装合法性

表中只列核心词条，剩余位置可用生存或战意词条。任意组合必须遵守词条允许部位，不能把两条同时要求武器的效果塞入同一件装备。

示例：多宝B四件昴日鸡，武器BREAK-01、护腕BREAK-02、衣服TACTIC-01、护肩CONTROL-01；四条分别合法，占四个部位。准提B武器留空或通用词条，护肩SHIELD-01、衣服SHIELD-02、护腕TACTIC-02；不能因武器没有盾词条就伪造额外槽位。

套装与法宝新增效果不是额外攻击预算的旁路。杨戬反击已达到3次后，即使镇岳印满足条件也不再攻击，装备界面应显示该共享上限。

## 3. 手算数值例

### 治疗与溢疗

1级女娲，攻击10000，杨柳甘露基础治疗=10000×50%+100=5100。

A常规+15%、基础被动+10%、A被动额外+10%、橙甘露瓶+8%、鬼金羊2件+10%，同池相加为+53%，主治疗=⌊5100×1.53⌋=7803。

目标缺失生命3000，则有效治疗3000、溢疗4803。仅女娲A的20%转盾时，盾=960；还需受目标最大生命15%的分支上限及总盾50%限制。若同时有溢疗成盾T3，合并转盾比例50%，得到2401，分支盾部分受15%上限、装备部分受20%上限，最终共同受总盾50%限制。

### 护盾加成

基础盾5000、准提A群盾+20%、星日马2件+12%、橙玄壁珠+8%，最终施加盾=5000×1.40=7000。目标最大生命10000且原有不同来源护盾1000，最多再接收4000，总盾达到5000。被上限截掉的3000不算吸收量、不能触发盾爆。

### 战意预算

队伍战意50，多宝战法基础35，节用T3减12，实际扣23、剩27，满足爆发预设保留20。若该次击破护盾且有破阵蓄能T3，额外+7变34；战法不得再获得常规技12战意。若同轮角色额外战意已拿10，本次只能再拿2。

### DOT不递归

毒伤每跳1000，橙瘟火葫+12%、DOT-03 T3增伤16%，同池+28%，本跳1280。以毒养毒T3回复⌊1280×6%⌋=76，再受每轮自身最大生命6%回复上限约束。此治疗不生成新的DOT、毒扩散或溢疗链。

## 4. 验收样例与平衡门槛

|场景|输入|精确预期|
|---|---|---|
|分支互斥|女娲从A切B|A的治疗+25%和溢疗转盾全部移除；B治疗−10%生效；基础技能等级不变|
|复活预算|同一目标已被两个不同来源各复活一次|第三个来源不得复活；技能不可因全体目标不合法而扣战意|
|反伤循环|双方均有反震|主攻击后只结算对应反震，不反震对方反震|
|援护链|黄飞虎、崇黑虎同时可分担|选择一个来源，最终生命损失不因递归分担复制|
|法宝品质|同角色由紫甘露瓶换橙|治疗加成6%→8%，触发次数、目标数不变|
|套装切换|星日马4件拆至2件|保留护盾+12%，下一场不再开场群盾；战斗中禁止换装|
|低血阈值|斩将刃目标生命比例恰好35%|不触发“低于35%”；34.99%触发|
|多段次数|哪吒B战法三段|扣一次战意、设一次CD；不因三段产三份基础战意|
|首领控制|孔宣对免疫硬控首领命中沉默|不沉默，减速10%一轮；不触发随机抵抗补偿|
|存档兼容|已有角色无分支记录|采用基础分支，不自动选择A，不改变旧装备和法宝ID|

平衡模拟计划：固定同等级/星级/装备属性预算，分别测试普通5目标、单首领、强盾、强疗、先手控制、反震敌人六类关卡；每组每档至少100个固定种子。统计胜率、回合数、每轮伤害/实疗/盾吸收、战意溢出、无效技能率和触发次数。

拟定回调门槛：同预算一种构筑在六类关卡全部比其他构筑胜率高15个百分点以上，或出现连续3轮全队满战意、长期总盾达到50%且零生命损失，必须复查预算。入门配装不以获得T3/金法宝为前提。上述为测试标准，不是已经测得的结果。
