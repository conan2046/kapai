## 2. 数值语言与成长

- `攻击`指该技能施法者的战斗攻击属性，不把旧字段名“法攻/物攻”未经核对地当作两套可叠加攻击。
- `最大生命`默认指条目明确的持有者；治疗/复活写“目标最大生命”，护盾写“施法者最大生命”时不得互换。
- `+20%伤害`表示加法进入同类增伤池；`暴击率+20个百分点`表示例如30%→50%，不是30%×1.2。
- 技能基础参数：`P(L)=P1+(L−1)×成长`，比例参数除10000进入计算，回合、次数和固定量不除10000。1级与10级仅是显示示例，10级不是满级设定。
- 分支固定加成、法宝特效、套装特效、词条品阶效果不随技能等级再次增长。装备基础属性继续沿用现有成长。
- 使用效果链的实际引用计算。客户端描述跨引用、显示绝对值等行为只作为历史基线展示，不据此改写战斗公式。
- 伤害和治疗最终向下取整；一次技能多段逐段取整。没有命中或完全免疫时不得计入“有效伤害”；护盾吸收算有效命中，不算生命损失。
- 统一生命比例判断：当前生命/最大生命；最低生命默认比较比例，只有旧技能明确写“当前生命值”时保留绝对值排序。相同比例按阵位从小到大；不使用隐藏随机挑选。

## 3. 战意、行动和冷却

|事件|基础战意|频次|
|---|---:|---|
|战斗开场|0|开场特效另计|
|普通攻击首次命中|8|每次主行动1次|
|常规技成功释放|12|每次主行动1次；治疗无有效目标时不施放|
|受到直接伤害|3|每名角色每主行动最多1次、每轮最多3次|
|击杀敌方非召唤单位|10|每次击杀1次|
|友方非召唤单位阵亡|15|每次有效阵亡1次；复活后的同角色再次死亡不再产此项战意|
|战法|扣逐人表数值|不额外获得常规技的12战意|

队伍共享0–100战意。追击、反击、反震、DOT、分伤和额外行动不获得普攻/常规技基础战意，只允许明确写出的特效产出。同一角色技能、装备、法宝的额外产战意总量每轮最多12；全队额外产战意每轮最多30。开场额外战意全队上限20。

“轮”统一为战斗全体单位完成一次正常行动机会的轮次；失去行动、死亡、复活、追加行动不刷新次数。V1中的“每回合”在V2按此轮次计数；这是一项拟调整，不能直接沿用现有施法者回合重置逻辑。持续状态在目标下一次正常行动结束扣1次；施加当下的行动不扣次。开场2回合增益在第2轮结束到期。

技能施放后设定CD=N；本人后续正常行动开始时先CD−1，减至0可使用。例如CD3技能第1轮施放，最早第4轮再次施放。额外行动不推进CD。每个技能每轮被动减CD合计最多2，最小0。减CD不能在当前事件递归释放同一个技能。

## 4. 结算顺序与全局上限

每段结算：合法目标 → 命中 → 该段控制前置条件快照 → 基础数值及增伤 → 暴击 → 防御/穿透 → 易伤与减伤 → 护盾/越盾 → 分担与生命扣除 → 死亡/免死/复活 → 后置状态 → 追击等追加事件。条目明确“先挂易伤再攻击”才改变顺序；默认本次新施加易伤不放大本次伤害。

|类别|V2统一规则|
|---|---|
|概率|基础概率+强化−抵抗，截断到0–100%；同事件同效果只抽1次；必定效果也受免疫规则约束|
|命中/闪避|最终命中率限制10%–100%；闪避不能使角色永久无敌|
|暴击|最终概率0–80%；暴伤总倍率1.5–3.0；无暴击标志优先|
|普通增伤|同类加法池，所有新增增伤总量最多+100%；斩杀条件增伤计入该池|
|穿透|多来源按 `1−Π(1−穿透率)` 合并，总忽视防御最多60%，防御不变负数|
|易伤|同名取最高；物理、法术、全伤按伤害适用范围加法，总易伤最多50%|
|减伤|普通减伤同类相加，总量最多60%；明确的物理免疫是独立状态，不被60%替换|
|分担|同一次原始伤害只选择1名援护者，先保护比例最低者；分担后不再援护或触发分伤链|
|护盾|同来源同名刷新、不同来源叠加，总盾≤目标最大生命50%；只追踪实际吸收，不把过期未吸收量计入吸收量|
|越盾|多来源越盾比例相加，总上限40%；穿透生命与扣盾两部分之和不得超过本次结算伤害|
|治疗|同类治疗加成相加，新增治疗加成池上限+100%；减疗总量0–100%；实疗=min(结算治疗,缺失生命)|
|溢疗|只计算主治疗的溢出；分配给扩散、转盾的总额不得超过该次溢出100%；二次治疗不再触发溢疗、净化、战意|
|额外攻击|追击、反击、协战合计每人每轮最多3次；技能更低上限优先；不能触发新的额外攻击|
|额外行动|每人每轮最多1次，不能再生成额外行动；复活当轮禁止额外行动|
|反震|以实际承受直接生命伤害为基准；每人每轮最多3次，不因反震/分伤/DOT再次反震；总反震比例上限50%|
|死亡/复活|同来源对同目标每场复活1次；同目标所有来源复活合计最多2次；免死每目标每场1次；次数不因死亡清零|
|DOT|同来源同类最多5层，持续至多5轮；刷新不补跳，回合开始结算；单来源每轮DOT伤害≤施法者攻击200%|
|负面类别|计类仅包含中毒、灼烧、流血、硬控、降攻、降防、减速、减疗、易伤、降命中、降抗；同类多个来源算1类|

反击、追击可暴击的条件继承该攻击类型，但不能触发吸血以外的新攻击；法宝/词条固定附伤、反震、DOT、死亡爆炸不暴击、不连击、不反击、不触发吸血。反击汲取是明确治疗特效，允许结算但仍受该词条回复上限。

首领：免疫沉默、睡眠、封印、混乱、反间、嘲讽、死亡禁锢。硬控命中改为减速10%、1轮，同目标每轮最多转化1次；死亡禁锢按通天B的易伤10%替代。首领减速总量最多20%、软属性削弱最多20%；免疫不视为随机抵抗，不触发失手补偿。V1“行动进度延迟”本轮统一改为对应数值的速度降低，1轮，不建立第二套行动条。

普通敌人连续同类硬控：第一次正常时长；第二次时长减半并向下取整、最少1轮；第三次免疫该类1轮。离开该控制2轮后清除连续记录。由不同队友施加也共享记录。

## 6. 策略预设

逐角色根据流派选择预设，玩家可以切换；只影响技能选择和目标，不额外加属性。

|预设|战意保留线|优先级与阈值|
|---|---:|---|
|救场|40|有阵亡且复活可用→最低友军<35%治疗→至少2人<70%群疗→常规→普攻|
|守护|30|保护目标<50%且无护盾/援护→自身<40%保命→敌人≥2且未被嘲讽→常规→普攻|
|控制|30|敌方最高攻击者无同类硬控→目标未降抗时先常规→控制战法→普攻；首领只允许软控替代|
|爆发|20|目标<35%斩杀→有易伤/降防时战法→常规→普攻|
|持续|20|优先无己方DOT目标→己方DOT≥3层时引爆/侵蚀→常规→普攻|

“保留线”表示普通战法施放后战意不得低于该数值。救场复活、低于35%的急救可越过保留线，但仍必须有足够战意；其余预设不能凭空透支。玩家手动战法可越过保留线。施放失败不扣资源、不启动CD。

3. 首批12人含较复杂的分支替换；其余47人主要为已有技能定向增强。需要评审角色强度预算后决定是否增加更多替换机制，而不是程序自行补设计。
4. 尚无战斗模拟支持这些数值的强度结论。完成组合验收与相同养成预算对照后再冻结版本。
