# 洞府第一模块：灵田交接

日期：2026-10-12。工程：`E:\neiwang_kapai\Game`；Unity：`unityclient`。用户授权将本轮洞府入口与灵田修改提交并推送到`origin/main`。

## 当前实现

- 主界面洞府按钮进入全屏`DongFuHome`；各洞府页面复用既有`DynamicUi_OneLevelLayer`顶部。其余四个建筑只有导航及页面框架。
- 灵田保留用户地图、36块地及卡片布局；按正式境界配置自动解锁，空地点击选中并展开种子栏，点有库存的作物直接种植，每次扣1粒。选中框独立于Plots，成熟点击直接收获；未成熟有作物时打开养护／铲除窗口。
- 缺水／虫害期间成长耗时延长20%，不叠加；处理后恢复正常。三阶段图片、列表图标、种子道具、时长、金币售价和产出均从表读取。
- 库存为0时复用`HeroEquipmentAutoRefine`购买弹窗，支持±1／±10数量；购买独立于地块，支持批量；金币收获走现有货币流程。
- 各地块使用用户Plot01样式的Scrollbar；未成熟显示进度，成熟显示Ready，删除旧Progress与Status。运行代码仅刷新内容、显隐、进度，以及共用选中框位置；布局与状态动画保留在预制体。
