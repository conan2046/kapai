# 《道友来封神》Steam 单机版标题流程与存档系统策划案 V1.2

> 状态：已按 2026-09-13 最终确认方案收口。V1.2 取消“主存档 + 历史备份”双层结构，改为最多 10 个扁平独立存档。

# 1. 设计目的

- 将原账号登录入口改为 Steam 单机标题流程。
- 玩家可以创建多个本地角色，并为同一角色保留多个不同时间点的完整进度。
- 所有存档统一展示在“旧的回忆”页面，不再额外提供备份分页、恢复列表或备份管理。
- Steam 离线时仍可创建、保存、读取和删除本地存档。
- 本地服务端、端口、连接、超时和协议等技术信息只进入 Unity 日志，不向玩家展示。

# 2. 名词解释

| 术语 | 定义 |
|---|---|
| 新的开始 | 创建一个新的本地账号标识并进入现有创角流程。 |
| 存档 | 某一时点的完整 SQLite 游戏数据库及其角色摘要；每个档位都是可独立进入的正式存档。 |
| 当前档位 | 本次进入游戏时使用的数据库档位。 |
| 另存档位 | 在游戏内把当前完整进度保存到另一个档位，形成可独立进入的历史时点。 |
| 旧的回忆 | 展示全部正式存档的统一入口。 |
| 临时快照 | 保存过程中生成的一次性 SQLite 一致性文件，仅用于安全写入目标档位，不是玩家可见的备份功能。 |

# 3. 产品模型

## 3.1 扁平存档

- 固定提供 `Slot01` 至 `Slot10`，最多 10 份正式存档。
- 不存在“角色主档下面再挂备份版本”的二级结构。
- 每个档位包含独立 `projectx.db` 与 `metadata.json`，点击后直接进入该时点的数据。
- 同一角色可以占用多个档位；这些档位拥有相同角色身份，但进度、等级、货币、背包、任务、世界状态等以各自数据库为准。
- 不同角色通过不同的新游戏流程创建，拥有各自的本地账号标识和角色数据。

示例：

| 档位 | 角色 | 保存时等级 | 进入结果 |
|---|---|---:|---|
| Slot01 | 角色A | 20 | 进入角色A的20级进度 |
| Slot02 | 角色A | 26 | 进入角色A的26级进度 |
| Slot03 | 角色B | 1 | 进入角色B的1级进度 |
| Slot04 | 角色B | 10 | 进入角色B的10级进度 |
| Slot05 | 角色B | 20 | 进入角色B的20级进度 |

## 3.2 数据边界

```text
Application.persistentDataPath/
  Saves/
    Slot01/
      projectx.db
      metadata.json
    ...
    Slot10/
      projectx.db
      metadata.json
    Pending/
      保存过程临时文件，成功后清理
```

- 玩家存档只枚举 `Saves/Slot01~10`。
- 旧开发路径 `LocalServer/projectx.db` 不自动展示为额外存档，避免“只创建一份却显示两份”的问题。
- 不再创建或读取玩家可见的 `Backups`、`Trash`、`Restarted` 等历史目录。
- 旧版本遗留的备份目录不主动删除，但新版本不再生成、枚举或恢复其中内容。

# 4. 核心流程

## 4.1 标题页

| 按钮 | 行为 |
|---|---|
| 新的开始 | 有空档时选择编号最小的空档，创建新的本地账号标识并直接进入创角流程；档位已满时进入覆盖选择。 |
| 旧的回忆 | 展示最多 10 个正式存档，点击任意存档进入其完整角色数据。 |
| 游戏设置 | 复用游戏内设置界面与选项。 |
| 离开游戏 | 关闭本地服务并直接退出游戏。 |

创角期间必须隐藏 `DynamicUi_jiemianjiazai`，不向玩家展示连接本地服务的过程。

## 4.2 新的开始

```text
点击“新的开始”
→ 查找编号最小的空档
→ 创建独立本地账号标识与干净数据库
→ 启动本地服务
→ 进入现有注册/创角流程
→ 创建1级初始角色
→ 写入角色摘要
```

- 新角色必须采用正式单机初始数据，不能继承本地测试用的满级、VIP、货币或解锁状态。
- 若没有空档，玩家选择一个已有档位并二次确认；确认后永久覆盖该档位。
- 新建失败时不得破坏原有档位。

## 4.3 旧的回忆

- 页面顶部复用 `OneLevelLayer` 风格。
- 存档卡片复用 `Layer/IntoGuild/Name` 样式。
- 最多展示 10 个档位，支持上下滑动。
- 已有档位显示角色名、头像、等级、战力、游戏时间和最后保存时间。
- 空档仅展示“空白回忆”；标题页进入时不显示创建按钮。
- 已有档位在标题页显示“进入游戏”和“删除存档”。
- 不显示备份页签、恢复按钮、版本列表或备份状态。

## 4.4 游戏内保存

- 游戏内通过设置界面的“保存游戏”打开存档页。
- 空档显示“保存回忆”，点击后把当前完整进度写入该档位。
- 已有档位隐藏“进入游戏”和“删除存档”，仅显示“保存回忆”。
- 保存到其他档位时，当前角色会新增一个可独立进入的历史时点。
- 保存到当前档位时，刷新当前数据库与摘要。
- 覆盖已有档位前必须二次确认；覆盖成功后旧内容永久替换。

## 4.5 删除

- 仅标题页“旧的回忆”允许删除存档。
- 删除前必须二次确认，并明确告知“永久删除”。
- 正在游戏中使用的当前档位不可删除。
- 删除后该档位立即变为空档，不提供回收站或备份恢复。

# 5. 保存一致性

## 5.1 在线保存

- 本地服务先把当前在线角色状态刷新到 SQLite。
- 通过 SQLite 一致性复制生成临时快照。
- 快照通过文件头与基础完整性检查后写入目标档位。
- 目标档位存在时先移动到临时替换目录，安装新档成功后立即删除旧目录。
- 安装失败时只在本次操作内回滚原档；回滚文件不会保留为玩家备份。
- 保存成功或失败后清理 `Pending` 临时文件。

## 5.2 异常与坏档

- 读取前检查数据库存在性和 SQLite 文件头。
- 坏档不得进入游戏，玩家可在标题页永久删除后重新创建。
- 不自动恢复旧备份，不静默替换损坏数据。
- 错误界面只描述玩家可执行的结果；数据库路径、端口、进程和堆栈写入 Unity Console。

# 6. 主界面联动

## 6.1 功能解锁

- 继续复用原项目功能开放等级逻辑。
- 1级角色只显示已解锁功能；未解锁功能图标保持隐藏。
- 功能达到开放等级后再显示对应图标。
- 隐藏功能时，其子节点红点同时隐藏。

## 6.2 红点系统

- 主界面红点继续由真实业务状态驱动，不使用固定测试红点。
- 切换存档后必须重新根据该档位的数据计算红点。
- 未解锁、Steam 排除或当前不可用的功能不得显示红点。

# 7. 单机通信表现

- 标题页、创角页和游戏内不显示“连接服务器、重连、连接超时、端口占用、本机服务”等信息。
- 本地服务启动失败统一使用“存档准备失败，请重试”等玩家语义。
- 技术详情写入 Unity 日志，便于开发排查。
- Steam 不可用或离线不阻断本地存档功能。

# 8. 界面状态矩阵

| 场景 | 空档按钮 | 已有档按钮 | 备份入口 |
|---|---|---|---|
| 标题页·旧的回忆 | 不显示创建按钮 | 进入游戏、删除存档 | 不显示 |
| 标题页·新的开始且档位已满 | 无空档 | 重新开始，二次确认覆盖 | 不显示 |
| 游戏内·保存游戏 | 保存回忆 | 仅保存回忆，二次确认覆盖 | 不显示 |

# 9. 实施范围

| 优先级 | 范围 | 当前要求 |
|---|---|---|
| P0 | 标题页、创角、10档存档、本地服务路径、正式初始角色 | 完整离线可玩，存档互不串档 |
| P1 | 游戏内保存、覆盖、删除、功能解锁、主界面红点 | 以当前档数据库为唯一业务状态 |
| P2 | 其余单机玩法与本地经济 | 随玩法迁移逐项确认持久化 |
| P3 | Steam平台能力 | 后续接入身份、成就；Steam Cloud不属于当前存档功能 |

保留的单机业务包括：主界面HUD、资源基础、装备/法宝、神将及培养、境界、副本/世界、寻宝、游历三界、封神玩法、摇钱树、幸运转盘、大富翁、每日答题、背包、任务和剧情对话。

每日答题已纳入功能地图：38道中文题、玩法大厅 `function_id=27` 入口、`/198 op=1/2` 十题循环、每日次数和最终奖励继续按当前实现运行。

# 10. 验收标准

| 编号 | 验收项 | 通过标准 |
|---|---|---|
| SP-01 | 新的开始 | 有空档时直接进入创角，不进入旧的回忆页面。 |
| SP-02 | 初始角色 | 新角色为正式1级初始数据，头像、货币、VIP与解锁状态符合单机配置。 |
| SP-03 | 存档数量 | 页面固定存在10个档位并支持上下滑动。 |
| SP-04 | 同角色多档 | 同一角色可保存两个以上不同时间点，分别进入后数据对应保存时点。 |
| SP-05 | 多角色多档 | 不同角色的多个存档在旧的回忆中扁平展示，互不串档。 |
| SP-06 | 当前档保存 | 保存当前档后重新进入，数据与保存时一致。 |
| SP-07 | 另存档位 | 保存到其他档位后，原档和新档均可独立进入。 |
| SP-08 | 覆盖 | 二次确认后目标档被当前数据永久替换，其他档位不变。 |
| SP-09 | 删除 | 标题页删除后档位变空，不产生可恢复记录。 |
| SP-10 | 重复存档 | 清空全部档位、新建一档并退出后，旧的回忆只显示一份已有存档。 |
| SP-11 | 功能解锁 | 1级仅显示已开放功能，未解锁图标与红点隐藏。 |
| SP-12 | 通信表现 | 玩家界面不出现服务器通信信息，技术详情仅在Unity日志中。 |
| SP-13 | 离线运行 | Steam离线时创建、保存、进入和删除均可完成。 |
| SP-14 | 异常保存 | 保存失败不破坏原目标档，临时文件可清理。 |
