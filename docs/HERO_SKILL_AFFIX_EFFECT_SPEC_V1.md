# 神将技能与装备特殊词条效果配置规格 V1

> 状态：首轮战斗模拟基线，不等同于最终平衡值<br>
> 适用范围：59名现有神将、当前4个有效装备位、现有10套装备<br>
> 前置方案：`HERO_SKILL_EQUIPMENT_BUILD_DESIGN.md`、`EQUIPMENT_SPECIAL_AFFIX_DESIGN.md`

## 一、设计目标与统一规则

本规格把前两份方案收敛为可直接制作配置表、战斗逻辑和测试用例的数值版本。首版不新增神将、不新增装备位、不重做73件法宝；保留现有技能的基础倍率和成长曲线，只增加技能职责、战法资源、流派分支、触发上限与装备特殊词条。

### 1.1 战斗资源：战意

| 规则 | V1数值 |
|---|---:|
| 队伍战意范围 | 0–100，共享资源 |
| 普通攻击命中 | +8 |
| 常规技成功释放 | +12 |
| 单次行动内首次受到伤害 | +3，每名角色每回合最多3次 |
| 击杀敌人 | +10 |
| 友方阵亡 | +15 |
| 战法 | 消耗对应战意，不再额外增加战意 |
| 自动战斗保留线 | 治疗/复活队默认保留40；控制队30；输出队20 |
| 溢出 | 超过100的部分舍弃；V1不做溢出收益 |

战意变化必须写入战斗日志，格式为：`来源角色/事件/变化值/变化后总值`。同一攻击的多段伤害只算一次“受到伤害”事件，反震、持续伤害和队友分担不重复产战意。

### 1.2 技能职责

每名神将的两个主动技能中指定一个“常规技”和一个“战法”。两个被动仍保留，但分别承担“核心被动”和“联动被动”。基础倍率继续读取现有 `skill_basic.xml`、`skill_active_effect.xml` 和 `skill_additive_effect.xml`；本规格中的百分比均为新增修正，配置落表时按字段要求转换为万分比或整数。

### 1.3 公共触发限制

- 追击、反击、协战：同一角色每回合合计最多3次；技能另有更低上限时取更低值。
- 额外行动：同一角色每回合最多1次，额外行动不能再次触发额外行动。
- CD减少：同一技能每回合最多减少2回合，不能低于0。
- 复活：同一目标每场最多被同一来源复活1次；复活回合不能立即获得额外行动。
- 硬控制：普通敌人同类控制连续命中后，第二次持续时间减半；首领不吃硬控，统一转为行动进度延迟。
- 护盾：同来源同名护盾只刷新、不叠加；不同来源累计护盾不超过目标最大生命50%。
- 持续伤害：同来源同类效果最多5层；层数刷新持续时间，不生成独立无限事件。
- 所有“每回合”限制以施法者回合计数；死亡再复活不重置次数。

## 五、互斥组与叠加顺序

| 互斥组 | 包含内容 | 规则 |
|---|---|---|
| EXTRA_ATTACK | 援护反击、击杀追击、额外行动、协战 | 同一角色每回合总计3次；额外行动单独最多1次 |
| RAGE_GAIN | SHIELD-04、COMBO-04、BREAK-04、TACTIC-02 | 可同时装备，但单角色每回合由词条获得战意最多12 |
| OPENING_RAGE | TACTIC-01及法宝开场战意 | 全队只取单条最高值，不求和 |
| TACTIC_COST | TACTIC-03及法宝减费 | 全队只取最高值，最低消耗20 |
| REVIVE_GUARD | HEAL-04及技能复活保护 | 同目标取最高减伤，不叠加 |
| CLEANSE_GUARD | HEAL-03及技能净化减伤 | 同目标取最高值，冷却独立保留 |
| CONTROL_EXTEND | CONTROL-02及技能延长控制 | 每目标2回合只允许成功一次 |
| DAMAGE_SPLASH | CRIT-03及其他击杀溅射 | 同一击杀只触发最高倍率一条 |

伤害计算顺序：基础倍率 → 攻防结算 → 技能分支增伤 → 目标易伤 → 暴击/连击 → 护盾与越盾分流 → 最终伤害 → 吸血/回复 → 击杀与余伤特效。减伤总上限60%，易伤总上限50%，防御降低总上限40%，行动进度单次变化上限20%。

## 八、实施分批与验收

### 8.1 分批

1. 数据清洗：修复描述占位符、24个缺失技能图标、重复技能名与共享ID 122。
2. 技能底座：技能标签、确定性AI、战意、公共触发上限、战斗日志。
3. 首批12名：落地本规格第三章的24套分支和自动策略。
4. 装备A批：先实现纯属性/已有事件可覆盖的17条特效。
5. 装备B批：补护盾吸收量、有效治疗、控制抵抗、余伤、行动进度等上下文。
6. 装备C批：接入战意类词条、词条重铸和推荐界面。
7. 扩展剩余47名：按第二章映射逐批补分支，不改变已验证的公共规则。

### 8.2 必须通过的验收

- 12名首批神将各有2套可用构筑，策略、套装、词条选择确实不同。
- 固定随机种子下，技能选择、词条生成和战斗结果完全可复现。
- 治疗无效释放率低于5%；无阵亡目标时复活释放率为0。
- 无护盾目标时自动释放戮仙剑的次数为0；无可控目标时不浪费沉默战法。
- 追击/反击/额外行动没有无限链；单回合次数与日志一致。
- 同战力仅更换构筑，至少能在“治疗首领、护盾首领、群攻首领”三个样本中改变两个样本的胜负或缩短20%以上战斗回合。
- 48条特殊词条逐条具备：触发、未触发、上限、互斥、死亡/复活、首领免疫六类自动用例。
- 旧装备和旧角色存档可加载；新增词条保存后重登、跨端读取不丢失。
- 装备推荐同时展示“基础战力”和“流派匹配度”，不得以绿色战力箭头替代流派判断。

## 九、平衡观测与回调条件

首轮模拟按同等级、同强化、同基础战力进行，每个流派至少运行1000场固定种子战斗。出现以下任一条件即回调：

- 单一T3词条使平均伤害或有效承伤提升超过18%。
- 单一构筑在三个机制样本中胜率均超过同品质其他构筑15个百分点。
- 控制队让普通敌方连续2回合完全无法行动的概率超过35%。
- 复活构筑把战斗时长拉长超过基线50%，且胜率提升不足5个百分点。
- 战意战法平均首次释放早于第2回合或整场平均释放少于1次。
- 任意角色由追击、反击、余震、余爆造成的间接伤害超过总伤害45%。

调参顺序固定为：触发频率 → 单回合上限 → 持续时间 → 数值倍率。不要先砍角色基础技能倍率，以免破坏没有特殊装备时的体验。
